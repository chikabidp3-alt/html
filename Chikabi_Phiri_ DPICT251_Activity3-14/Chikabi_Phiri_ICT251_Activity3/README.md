# Chikabi Phiri - ICT251 Activity 3

Interactive Personal Website built from my Activity 2 website.

## Four JavaScript features
1. Contact form validation and local preview.
2. Gallery viewer with Previous/Next controls.
3. Project/Skills search and reset filter.
4. Light/Dark theme switch.

The project also includes expandable project details and a mobile navigation menu.

## Folder structure
- `index.html` - main webpage
- `css/styles.css` - external styling
- `js/script.js` - JavaScript features
- `images/` - Activity 2 personal photos
- `videos/` - Activity 2 video and audio

## How to test
Open `index.html` with VS Code Live Server.
- Test navigation on a narrow screen.
- Switch between Light and Dark themes.
- Search for HTML, CSS or JavaScript in Projects.
- Open and close project details.
- Use Previous and Next in the gallery.
- Submit empty/invalid contact fields, then submit valid details.
- Check the browser console for errors.

## Render settings
Root Directory: blank
Build Command: `echo "No build required"`
Publish Directory: `.`
Auto Deploy: enabled
